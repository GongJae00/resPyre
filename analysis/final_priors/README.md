# Windowed Reliability Priors

This directory stores target-computable windowed reliability priors generated by
`execute.md`.

Required files before full materialization:

- `cohface_mahnob_target_computable_reliability_windowed.csv`
- `mahnob_target_computable_reliability_windowed.csv`
- `mahnob_state_component_reliability_windowed.csv`

The edge-level CSVs produced by `extract_target_reliability_graph_features.py`
are intentionally not retained in the public release because they are large
intermediate diagnostics. Regenerate them from `execute.md` only when auditing
the reliability graph itself.

Older trial-level priors are excluded from the release surface.
