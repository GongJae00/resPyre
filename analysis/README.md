# Analysis Outputs

This directory is the default location for generated analysis outputs.

Only this README and `final_priors/README.md` are tracked. Generated CSV, JSON,
Markdown, and figure artifacts are ignored by Git.

Typical generated outputs include:

- dataset-scope summaries
- target-computable reliability priors
- rate-source and observability diagnostics
- statistical comparison tables

Use `execute.md` to regenerate the release outputs.
